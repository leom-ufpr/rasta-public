# Rasta: R6 Package for Ensemble Learning in Ecological Niche Modelling

#### IMPORTANT: scripts used to generate (from scratch) the rasters used in the paper are in the folder `/pipeline`. We refer the interested reader to the README file in that folder.

**Note to Reviewers:** This repository contains the source code for the `Rasta` package, a companion software to the manuscript currently under review. To maintain double-blind anonymity, the package is hosted here rather than on a public version control platform. Functions used to tune, train and test models are in `scripts/train_test_lib.R` and `scripts/tuning_lib.R`.

**Rasta** is an R package aimed at ensemble learning using information theory, built on the [R6](https://r6.r-lib.org/) system. Rasta uses as input data `terra` multilayer `SpatRasters` generated by ENM algorithms of your choice. It returns ensemble predictions of species occurrences by combining the outputs of individual algorithms, using either raw or weighted suitability values computed from individual models. The package also returns rasters with model weights, instability (measured as normalized Rao's entropy) and ensemble efficiency, all calculated on a cell-by-cell basis.

## Prerequisites

To ensure a smooth installation of the package and its dependencies, we recommend using the `pak` package manager. It is significantly faster and more reliable than the standard `utils::install.packages` function for local source files with complex dependencies.

If you do not have `pak` installed, please run:

```
R
if (!"pak" %in% rownames(installed.packages())) {
  install.packages("pak")
}
```
It is also recommended to install RTools:
```
if (!"RTools" %in% rownames(installed.packages())) {
  install.packages("RTools")
}
```

## Installation

The following R script performs all steps needed to download, install, and configure `Rasta` and its data in an isolated environment.  
Copy–paste the entire block into an R session and adapt the base directory path as needed.
```
#### 1. Create base directory and set it as working directory ####

# Define your base directory (edit this path as desired)
base_dir <- "/path/to/rasta_project"

if (!dir.exists(base_dir)) {
  dir.create(base_dir, recursive = TRUE)
}

setwd(base_dir)
cat("Working directory set to:", getwd(), "\n")


#### 2. Create subdirectories: anon-rasta, rasta_lib, rasta_data ####

subdirs <- c("anon-rasta", "rasta_lib", "rasta_data")

for (d in subdirs) {
  if (!dir.exists(d)) {
    dir.create(d, recursive = TRUE)
  }
}

cat("Subdirectories created in base directory:\n")
print(list.files("."))


#### 3. Verify if pak is installed; if not, install it ####

if (!"pak" %in% rownames(installed.packages())) {
  install.packages("pak")
}
library(pak)


#### 4. Download the zipped tarball of the package ####

options(timeout=3000)

zip_url  <- "https://anonymous.4open.science/api/repo/anon-rasta-review/zip"
zip_file <- file.path(base_dir, "anon-rasta.zip")

download.file(url = zip_url, destfile = zip_file, mode = "wb")
cat("Downloaded package zip to:", zip_file, "\n")


#### 5. Expand the zipped file into subdirectory `anon-rasta` ####

unzip(zipfile = zip_file, exdir = file.path(base_dir, "anon-rasta"))

cat("Contents of anon-rasta directory:\n")
print(list.files(file.path(base_dir, "anon-rasta")))


#### 6. Locally install Rasta into `rasta_lib` using pak::local_install ####

# Save current library paths
old_libpaths <- .libPaths()

# Prepend rasta_lib to library paths so that installation goes there
rasta_lib <- file.path(base_dir, "rasta_lib")
if (!dir.exists(rasta_lib)) {
  dir.create(rasta_lib, recursive = TRUE)
}
.libPaths(c(rasta_lib, old_libpaths))

# Identify the root of the unpacked Rasta package.
# Depending on how the zip expands, this may be a directory containing DESCRIPTION.
anon_root <- file.path(base_dir, "anon-rasta")

# If there is a single top-level folder inside anon-rasta, use that as root.
anon_contents <- list.files(anon_root, full.names = TRUE)
if (length(anon_contents) == 1 && dir.exists(anon_contents)) {
  anon_root <- anon_contents[1]
}

cat("Using package root:", anon_root, "\n")

# Install from local source with pak
pak::local_install(root = anon_root, upgrade = FALSE)

cat("Installed packages in rasta_lib:\n")
print(installed.packages(lib.loc = rasta_lib)[, "Package"])


#### 7. Expand `rasta_data.tar.gz` into subdirectory `rasta_data` ####

# Locate the installed package path within rasta_lib
rasta_pkg_path <- find.package("Rasta", lib.loc = rasta_lib)

data_tarball <- file.path(anon_root, "inst", "extdata", "rasta_data.tar.gz")
if (!file.exists(data_tarball)) {
  stop("Could not find rasta_data.tar.gz in inst/extdata of the installed package.")
}

rasta_data_dir <- file.path(base_dir, "rasta_data")
if (!dir.exists(rasta_data_dir)) {
  dir.create(rasta_data_dir, recursive = TRUE)
}

untar(tarfile = data_tarball, exdir = rasta_data_dir)

cat("Expanded data into rasta_data directory. Contents:\n")
print(list.files(rasta_data_dir, recursive = TRUE))


#### 8. Load Rasta from rasta_lib ####

# Ensure rasta_lib is first in the library path
.libPaths(c(rasta_lib, old_libpaths))

library(Rasta)

cat("Rasta loaded successfully from rasta_lib.\n")

# Your analysis code using Rasta can follow below.
```

## Quick Start
### 1\. Load Libraries and Data

```
R
library(Rasta, lib.loc="/path/to/rasta/library") # Tell R where to find Rasta 
```

### 2\. Initialize your Rasta object

```
# Add `cli` to your library for a friendlier experience
if (!"cli" %in% rownames(installed.packages())) {
  install.packages("cli")
}

# Define the cutout code
code <- "atl" # S. radians
#code <- "crb" # S. siderea
#code <- "brz" # S. stellata

# Define data directory and method list
data_dir<-file.path(anon_root, "inst", "extdata")
methods <- c("bioclim", "gower", "enfa", "gam", "glm", "mars", "ann", "maxent", "svm")
rast_list <- list()

# Create list with all multilayer `SpatRasters` for `S. radians`
msg <- "Reading SpatRasters from disk, please wait..."

for(model_idx in cli::cli_progress_along(METHODS_BY_CAT, name = msg)){
    model <- methods[model_idx]
    file_name <- paste0(code, "_", model, ".tif")
    file_path <- file.path(DATA_DIR, file_name)
    rast_list <- c(rast_list, terra::rast(file_path))
}

message()

radians_rasta <- Rasta$new( class = code,
                            replicates = 100,
			    stacks = RAST_LIST,
			    methods = methods )

### 3\. Getting results

Most `Rasta` methods return standard `SpatRaster` objects, which can be plotted or saved immediately. The first call to a method will likely take a while due to expensive raster algebra, but subsequent method calls will return results faster because they will take advantage of previous computations. Expensive data are internally stored so a second call to the same method function will return the stored object in no time.

Start by checking object's metadata:
```
radians_rasta$replicates # Returns 100
radians_rasta$intervals # Returns 10
all(methods %in% radians_rasta$methods) # Returns TRUE
```

If values are as expected, the object was correctly instantiated. To get the raster layer corresponding to Fig. 1a, use the following function (will take a while, so be patient...):
```
radians_suitability_raster <- radians_rasta$get_mean_ensemble_raster()
```

The second call to the same function is much faster because the raster object was internally stored:
```
radians_rasta$get_mean_ensemble_raster()
```

Now get the raster layer corresponding to Fig. 1b (be patient):
```
radians_wgt_suit_raster <- radians_rasta$get_wgt_ensemble_raster()
```

To get the raster layer corresponding to Fig. 1c, run:
```
radians_diff_raster <- radians_wgt_suit_raster - radians_suitability_raster
```

Get the raster layer to Fig. S10a:
```
radians_bioclim_wgt_raster <- radians_rasta$get_weight_raster("bioclim")
```

Get the raster layer to Fig. S10b:
```
radians_bioclim_wgt_raster <- radians_rasta$get_weight_raster("gower")
```
...and so on...


Let us move to Fig. 2. Run the following command to get the raster layer corresponding to Fig. 2a:
```
radians_efficiency_raster <- radians_rasta$get_efficiency_raster()
```

Raster layer corresponding to Fig. S5a:
``` 
bioclim_suit <- radians_rasta$get_mean_suitability_raster("bioclim")
```

Raster layer corresponding to Fig. S5b:
``` 
bioclim_suit <- radians_rasta$get_mean_suitability_raster("gower")
```
...and so on...


Raster layer corresponding to Fig. S8a:
```
bioclim_uncertainty_raster <- radians_bioclim_stash$get_entropy_raster()
```

...etc..


Data for the plot in Fig. 3a were generated by bootstrapping overall instability associated with each method. To get the uncertainty score, run (this will take between 30 mins and 1 hour **per method**, depending on your machine and number of replicates):
```
bioclim_entropy <- radians_rasta$get_entropy("bioclim")
```

By default, the same number of pseudo-replicates as the number of cross-validation experiments (n = 100) will be used if no argument is passed to the method.
```
radians_bioclim_bs_tibble <- radians_rasta$bootstrap_entropy("bioclim" )
```

You may set a different value, if you will:
```
radians_bioclim_bs_tibble <- radians_rasta$bootstrap_entropy(method = "bioclim", reps = 1000)
```

And you may change the seed:
```
radians_bioclim_bs_tibble <- radians_rasta$bootstrap_entropy(method = "bioclim", reps = 1000, seed = 2L)
```
**IMPORTANT**: keep seed constant among methods if you want to maintain the repeated measures design.


To get the global mean entropy for "bioclim":
```
radians_bioclim_mean_entropy <- radians_rasta$get_mean_entropy("bioclim")
```

## Class Reference: `Rasta`

The `RastaStash` class is the workhorse of the package, designed to instantiate rich objects containing all necessary methods to implement ensemble learning in Ecological Niche Modeling (ENM) using information theory.

### Public Methods

#### Constructors

#### `new(...)`
Creates a new `RastaStash` object.

* **Parameters**:
    * `stash`: (Optional) A list of `RastaLand` or `RastaStash` objects. If omitted, returns an empty object that can be populated later using `add()`.
    * `.enforce_binary`: (Logical, Dev only) Default: `TRUE`.
    * `.profile`: (Logical, Dev only) Default: `FALSE`.
    * `.verbosity`: (Integer, Dev only) Default: `0`.
* **Returns**: A new `RastaStash` object.
* **Details**: You may pass a mixed list of `RastaStash` and `RastaLand` objects. Ensure all objects share the same `class` attribute and identical replicate counts.

#### `add(rasta_object)`
Populates the stash with `RastaLand` objects or other `RastaStash` objects.

* **Parameters**:
    * `rasta_object`: A valid `RastaLand` or `RastaStash` object.
* **Returns**: `TRUE` if the object was correctly added.
* **Details**: Ensures consistency in `class` attributes and replicate counts before adding.

#### Metadata acessors

#### `get_class()`
Accessor to the object's class label (e.g., the taxon name).

* **Returns**: A string representing the class label, or `NULL` if the stash is empty.

#### `get_all()`
Retrieves all objects stored in the stash.

* **Returns**: A list of all `RastaLand` objects currently in the stash. Returns an empty list if the stash is empty.

#### `get_by_index(i)`
Accessor to `RastaLand` objects based on their order in the stash.

* **Parameters**:
    * `i`: Positive integer corresponding to the object index.
* **Returns**: A `RastaLand` object or `NULL` if empty.

#### `get_by_method(method)`
Accessor to `RastaLand` objects generated by a specific SDM algorithm.

* **Parameters**:
    * `method`: A string representing a valid method name (e.g., "ann", "glm").
* **Returns**: A list of `RastaLand` objects.

#### `get_by_rep(i)`
Accessor to `RastaLand` objects corresponding to a specific replicate number, regardless of the algorithm used.

* **Parameters**:
    * `i`: Integer corresponding to a valid replicate number.
* **Returns**: A list of `RastaLand` objects.

#### `get_methods()`
Lists all SDM algorithms contained in the stash.

* **Returns**: A vector of method names in alphabetical order.

#### `get_method_count()`
Returns the number of unique methods (SDM algorithms) in the stash.

* **Returns**: A positive integer (or 0 if empty).

#### `get_method_count_list()`
Returns a count of `RastaLand` objects per method.

* **Returns**: A list indexed by method names containing the object counts.

#### `get_rep_count()`
Returns the number of replicates used to generate the stash.

* **Returns**: A positive integer (or 0 if empty).

#### `get_rasta_land_count()`
Accessor to the total number of `RastaLand` objects in the stash.

* **Returns**: An integer (> 0 for populated objects).

#### `get_raster_size()`
Accessor to the raster size (count of non-NA pixels).

* **Returns**: An integer, or `NULL` if empty.

#### `has_stash()`
Checks if the object is populated.

* **Returns**: `TRUE` if populated with `RastaLand` objects; `FALSE` otherwise.

#### `has_methods()`
Checks if the method list has been internally assembled.

* **Returns**: `TRUE` if populated and methods are assembled; `FALSE` otherwise.

#### Data methods

#### `bootstrap_uncertainty(bs_reps = NULL, bs_matrix = NULL)`
Bootstraps uncertainty by random re-sampling of the binary rasters.

* **Parameters**:
    * `bs_reps`: Integer. Number of desired pseudo-replicates. Defaults to the number of replicates in the stash if omitted.
    * `bs_matrix`: A design matrix to enforce a repeated measures design. If provided, `bs_reps` is ignored.
* **Returns**: A list containing:
    1.  `bs_uncertainty`: Vector of bootstrapped uncertainty values.
    2.  `bs_matrix`: The design matrix used.
* **Details**: Calculates uncertainty as the sum of pixel entropies. Passing a `bs_matrix` allows you to ensure the same resampling experiments are used across different algorithms (e.g., ensuring ANN and GLM use the same validation sets).

#### `get_uncertainty()`
Calculates the total uncertainty of the stash.

* **Returns**: A numeric value representing the sum of entropies of every pixel in the uncertainty raster.

#### `get_uncertainty_raster()`
Retrieves the spatial uncertainty representation.

* **Returns**: A `RasterLayer` object representing uncertainty.

#### `get_prob_raster()`
Retrieves the unweighted probability raster (voting).

* **Returns**: A `RasterLayer` object.

#### `get_wgt_prob_raster()`
Retrieves the weighted probability raster.

* **Returns**: A `RasterLayer` object.

#### `get_weight_stack()`
Retrieves the weights computed for each algorithm.

* **Returns**: A `RasterStack` object containing the weights.
